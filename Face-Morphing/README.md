The original code for this application was written in 2017 as part of my MSci capstone project. Since then, I have cleaned up the code with the assistance of Claude to increase redibility, though the foundational logic remains the same. 

This program can be run from the file Morphing.java and run it. A GUI will pop up. Click on the two buttons above the boarders to select the face images you wish to morph (only jpgs are accepted). Instructions will then appear for which points on the face images to select. Once the coordinate selection process is complete, you will be able to morph the two images together. The program offers the option to show different ratios between the two imput images as well as a film strip where different stages of a full transformation are laid out alongside each-other.
